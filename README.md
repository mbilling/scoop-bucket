# mbilling/scoop-bucket

[Scoop](https://scoop.sh) manifests for [fss-mqtt](https://github.com/mbilling/fss-mqtt), an
interactive terminal MQTT v5 explorer, on Windows.

```powershell
scoop bucket add mbilling https://github.com/mbilling/scoop-bucket
scoop install fss-mqtt
scoop update fss-mqtt      # later releases
```

`bucket/fss-mqtt.json` is updated automatically by the fss-mqtt release workflow; don't edit it by
hand.
